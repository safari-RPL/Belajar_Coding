Java Script

JavaScript adalah bahasa pemrograman yang digunakan untuk membuat website menjadi lebih interaktif dan dinamis. JavaScript dapat digunakan untuk membuat tombol yang dapat diklik, menampilkan pesan, mengubah teks atau warna, melakukan validasi form, serta membuat berbagai fitur interaktif lainnya. JavaScript biasanya digunakan bersama HTML dan CSS, di mana HTML berfungsi sebagai struktur halaman, CSS untuk mengatur tampilan, sedangkan JavaScript untuk mengatur fungsi dan interaksi pada website.


HTML

HTML adalah bahasa markup yang digunakan untuk membuat struktur dan isi sebuah halaman website. HTML digunakan untuk membuat berbagai elemen seperti judul, paragraf, gambar, tabel, tombol, link, dan formulir. HTML menjadi dasar atau kerangka utama sebuah website agar setiap bagian halaman dapat tersusun dengan baik.


CSS

CSS (Cascading Style Sheets) adalah bahasa yang digunakan untuk mengatur tampilan dan desain sebuah halaman website. CSS dapat digunakan untuk mengatur warna, ukuran teks, jenis font, jarak, posisi, ukuran elemen, serta tata letak halaman. Dengan CSS, website yang dibuat dengan HTML menjadi lebih menarik, rapi, dan mudah dilihat.
